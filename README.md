# 九鼎记 · 第一章「洛水青铜」

以《轩辕剑》式的上古神话世界观为灵感、借鉴《八方旅人》HD-2D 视觉风格的网页 JRPG Demo。像素角色站在立体的低多边形场景里，带移轴景深、体积光、泛光、宣纸质感调色和水墨转场。所有美术、音乐、音效均由代码程序化生成，不依赖外部素材。

## 运行

```bash
npm install
npm run dev      # 打开 http://localhost:5173
npm run build    # 产物在 dist/，可直接部署为静态网站
```

操作：方向键 / WASD 移动（Shift 疾行），空格 / 回车 / Z 确认与调查，Esc / M 打开行囊菜单。战斗中用 ←→ 或 Q / E 调整「蓄气」。支持触屏虚拟摇杆。

## 故事

> 上古之时，黄帝采首山之铜，铸鼎于荆山之下。鼎成九尊，分镇九州地脉。
> 三千年后，九鼎沉没于烟尘之中——直到洛水，开始发光。

墨家旁支的少年机关师**墨衡**在洛水渡捞起一块刻着饕餮纹的青铜残片。为了弄清残片的来历，他穿过妖物横行的竹海，前往北山的墨家旧坊寻找师叔墨拙。途中，他与追寻「鼎气」而来的南疆巫女**巫月**结伴同行。

第一章共三张地图，正常游玩约 30–40 分钟：

## 系统

- **破绽与弱点**：妖物有护盾和隐藏弱点，五行（金木水火土，相克循环）或兵器（剑、弩、符）击中弱点就能削减护盾。护盾归零时进入「破绽」：停止行动两回合、受到的伤害翻倍。
- **蓄气**：每回合积攒 1 点气（上限 5），出招时最多投入 3 点，普攻和连击招式增加段数，术法威力成倍提升。
- **炼妖·摄魂**：用青铜残片封印处于破绽状态的妖物，获得妖魄，再在菜单中炼化成丹药和符箓。这是对轩辕剑「炼妖壶」的致敬。
- **招式**：墨衡用墨家剑术和机关术（墨剑·流光、天罡剑气、机关·连弩、墨斗·缚灵线、机关·木鸢），巫月用南疆巫术和五行符咒（离火·焚天符、坎水·寒澜符、坤土·岩崩符、蛊术·回春、巫咒·灵护、炎阵·朱雀）。每个招式都有专门的演出。
- **道具与装备**：消耗品（回春散、清心露、还魂香、雷火弹、桂花茶）、永久强化的符箓、兵器 / 护甲 / 饰物三个装备位，另有商店、宝箱和要物。
- **Boss 机制**：饕餮之影会蓄力施放「饕餮吞天」，在它出手前打出破绽就能打断；血量降到一半时进入二阶段，重铸护盾、改变弱点，并召唤鼎魂火。

## 技术

- Three.js 渲染，后处理管线依次为：泛光 → 移轴景深 → 宣纸纹理 / 分离色调 / 暗角 / 颗粒。
- 高大物体挡住角色时，会做抖动网点式的淡出。
- 像素人物与妖怪先用 Canvas 绘制，再经阈值化处理并自动描边。
- 音乐由 WebAudio 实时合成，用古筝拨弦、笛子、鼓、锣，按五声音阶编曲。
- 字体使用马善政毛笔楷书和思源宋体，按游戏实际用到的字符裁剪成子集（`python3 tools/subset_fonts.py`）。
- 性能：静态道具按材质合批，帧率持续偏低时自动降低渲染分辨率。高大物体遮挡角色时做网点淡出，竹林高度按视线距离衰减。

开发接口与测试工具（快速剧情测试 `?fast`、自动通关脚本等）见 [`docs/ENGINE.md`](docs/ENGINE.md)。
